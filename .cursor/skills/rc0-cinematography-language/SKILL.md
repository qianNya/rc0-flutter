# RC0 电影摄影语言

用可持久化的摄影参数说话。每个数值都对应一种观看距离或一种平台画布，不写无法执行的形容词。

## 何时使用

- 设定或解释 `shotType`、`cameraMovement`、`lensMm`、`aspectRatio`。
- 设计电影预设：`CinePresetItem` 的 `aspectRatio`、`frameRate`，以及帧上的 `cinePresetId`。
- 审阅剧本详情里「画幅 · 景别」这类摄影摘要。
- 把横屏电影语言改写成竖屏信息流语言，或反过来。

## 领域立场

摄影是距离的艺术。景别决定观众离人物多近，焦段决定空间是否诚实，运镜决定谁在推动时间。画幅是放映场地：影院、桌面和手机不是同一种舞台。

## 与 RC0 模型的映射

帧级字段在 `DraftFrameData`：

| 字段 | 默认 | 含义 |
|---|---|---|
| `shotType` | `medium` | 景别 |
| `cameraMovement` | 空字符串 | 运镜；空表示固定 |
| `lensMm` | `35.0` | 焦距毫米 |
| `aspectRatio` | `16:9` | 画幅 |
| `cinePresetId` | 空 | 指向成套摄影预设 |

预设级字段在 `CinePresetItem` / `CinePresetDetail`：`aspectRatio`、`frameRate`，以及色彩相关的 `colorSpace`、`lut`（色彩语义见 `rc0-color-lut-identity`）。

## 取值约定

景别使用稳定英文标识，界面可以另做中文展示，存储值保持一致：

- `extreme_wide` 环境压过人物
- `wide` 人物与空间同时可读
- `medium` 默认对话距离
- `close` 情绪与道具
- `extreme_close` 证据或生理细节

焦段：

- `24` 空间夸张，适合建立与追逐
- `35` 默认，接近人眼，适合关系戏
- `50` 人物自然，背景开始退后
- `85` 特写与隔离

运镜用短动词短语：`static`、`push`、`pull`、`pan`、`tilt`、`track`、`handheld`。没有运动就留空或写 `static`，不要写「镜头感很强」。

画幅与发行场地一起选：

- `9:16` 单手信息流、短剧封面
- `16:9` 桌面与常规视频
- `2.39:1` 只在作品明确要求宽银幕时使用，且封面需另裁一版竖图

帧率写在预设上，同一支片子不在中途无理由切换。对话与写实默认跟随预设；升格只标注在需要时间变形的镜上，并在该镜说明里写明动机。

## 创作原则

1. 一场之内画幅不变。画幅是放映合同，不是单镜滤镜。
2. 焦段跳变必须伴随景别或场面调度的理由，避免同一对话来回在 24 与 85 之间无动机对切。
3. 运镜服务于句子里的动词。对白镜默认固定，动作镜才跟踪。
4. 预设是一整套观看方式。帧引用 `cinePresetId` 后，不要在帧上悄悄改掉画幅却不解释。
5. 竖屏构图把主体放在上半与中部，底部留给界面对话与字幕安全区。

## 互联网创业约束

- 预设是可复用的摄影产品，名称描述观看感受与画幅，不描述内部 id。
- 同一模板下的帧应共享一个主预设，便于买家一键套用。
- 封面裁切服从画幅，不把宽银幕硬拉成正方形。

## 实现时遵守

- 摄影参数留在草稿帧与预设实体，不散落在 Widget 常量里。
- 展示文案可以中文，持久化值保持上表标识，避免中英文混存。
- 预设详情与帧编辑分属 `cine_preset` 与 `screenplay_draft`，通过 id 关联，不互相复制整套字段。

## 产出检查

- 每镜的景别、焦段、运镜都能对应一个叙事理由。
- 一场只有一个画幅。
- 预设上的画幅、帧率与帧级引用一致。
- 竖屏作品的主体没有落在系统手势区。

## 相关技能

格与格的顺序用 `rc0-storyboard-sequential-art`，色彩与 LUT 用 `rc0-color-lut-identity`，对白节奏用 `rc0-short-drama-writing`。
