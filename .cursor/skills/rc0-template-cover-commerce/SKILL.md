# RC0 模板封面与视觉商品

模板是被陈列的艺术品。封面是橱窗，幕场结构是货架内部，徽章只是橱窗上的一小块标签。

## 何时使用

- 设计模板市场、模板详情、首页模板轮播与快捷入口。
- 填写或展示 `TemplateItem`、`TemplateDetail`、`TemplateBadge`。
- 决定一部作品如何被封面、标题、标签和作者信息卖掉，同时仍像一件作品。

## 领域立场

卖点来自作品里已经发生的图像，不来自额外贴上去的促销层。买家应在封面上看见类型、情绪和完成度，点进去看见幕与场，而不是看见另一套广告。

## 与 RC0 模型的映射

市场卡片 `TemplateItem`：`title`、`coverUrl`、`authorName`、`badge`（`hot` / `newItem`）、`likes`、`comments`。

详情 `TemplateDetail` 增加 `authorAvatarUrl`、`authorLevel`、`views`、`tags`、`acts`。一场的试读是 `SceneItem` 的标题、缩略图和 `frameCount`。

首页轮播使用市场 banners；快捷入口里的「图片 / 剧本 / 分镜 / 预设」是不同门类，不要都做成同一种商品卡。

## 创作原则

1. 封面取自作品的转折格，不取无事件的空镜，不取只有文字的标题卡。
2. 标题是作品名，不是营销句。营销句若需要，放在标签或场标题，不污染 `title`。
3. `hot` 表示正在被使用或讨论，`newItem` 表示新上架。二者不同时叠加成第三种徽章。没有依据就不显示徽章。
4. 标签描述类型与情绪，数量克制，能帮助检索。标签不重复标题里的词。
5. 作者名、等级、头像是信用，不是装饰。等级只反映平台既有口径，不在卡片上发明新等级体系。
6. 详情页的幕与场是试读目录。第一场应可被理解，后续场可以保持悬念，但标题不能是「付费解锁」这种非叙事文案。

## 互联网创业约束

- 点赞和评论是社会证明，展示数字，不把数字写成「爆款保证」。
- 轮播只放已经有封面、作者和结构的模板，不放空活动占位。
- 从市场进入预设、帧查看器时，深链指向该模板自身的画幅与分镜，不串到别的作品。

## 实现时遵守

- 市场数据经 `template_market` 的 Provider → UseCase → Repository，页面不直接请求。
- 卡片列表用 builder。封面用缓存图片，并处理加载与失败占位。
- 徽章枚举只有 `hot` 与 `newItem`。新状态先扩展领域模型，再出现在 UI。

## 产出检查

- 封面、标题、第一场说的是同一个故事。
- 无徽章的作品仍然完整可看，徽章不是可点击的唯一理由。
- 作者信息在卡片和详情上一致。
- 试读目录的场数、格数和真实结构一致。

## 相关技能

封面的画格选择用 `rc0-storyboard-sequential-art`，封面色彩用 `rc0-color-lut-identity`，作者信用用 `rc0-creator-persona-art`。
